Div'd Up Backgrounds

Scroll down to see the different backgrounds on this page, and how they move!
The page is divided into sections, each with its own background image. The images are set to move as such to create a sort of parallax effect when scrolling through the page.

How is it done?

This page is separated into seperate divs, nested inside the parent "scrollContent" div.
The divs that actually define which image is show are the "scrollContainer" divs. Each of these divs has a background image set in the CSS file, and the images are set to move with the scroll position of the page.

Scroll Containers

For example, this is the second scroll container. You know this because it also has the id of "scrollC2", which is what the CSS file uses to set the background image.

Good for modularity

You can easily add or remove scroll containers from this page, and the CSS will still work. The only thing you need to do is make sure that the id of the div is the same as the id in the CSS file, and that the div is inside the "scrollContainerBox" div, which is a child of the "scrollContainerParent" div of the same id as the corresponding scroll container. This is how the CSS file knows which image to use for each scroll container.
The div above this one, at the top of the page, is the first scroll container, and has the id of "scrollC1". The div below this one is the third scroll container, and has the id of "scrollC3". You get the idea.

Why so much nesting?

Because it lets you do more with these boxes, as long as you edit the CSS file.


For example, the scrollContainer below this one (scrollC4) contains a clickable box that will take you to a different page and is formatted differently to communicate this better.

Nesting makes it easier to edit things!

These boxes can be edited within the CSS file like they are here because of this nesting. It's a pattern derived from the technique used to create the scrolling backgrounds on this page, just expanded.
The JavaScript used to create this scrolling effect is actually very simple, and is just a few lines of code. It uses the scroll position of the page to determine how far down the page you are, and then sets the background image to move based on that by cleverly changing the CSS styling of the divs.

Scripting

Believe it or not, it was more work to get the text to fade in and out than it was to get the images to scroll. The text is set to fade in and out based on the scroll position of the page, and is done by using the "opacity" property of the style object of the div.
Once the user scrolls down to a certain point, the text will fade in, and once they scroll back up, it will fade out. "Math.max" and "Math.min" functions and a set 'threshold' say when the text will fade in and out based on where the user is on the page.

I can put a few boxes here

You can write as much as you'd like in these boxes, and they will scroll with the page. About six boxes will fit in these spaces.
These boxes are laid out in this way thanks to a flexbox courtesy of display: flex; in the CSS file. This allows for a more modular design, and allows you to add or remove boxes without having to worry about the layout of the page. Well, you do have to worry about the layout of the page, but not as much as you would if you were using a table or something like that.

Oh, and images work too.
